## 版本竞争与恢复

在 16 个可达状态、28 条转移中，保留发布前版本核验时未发现旧结果成为当前有效证明。删除核验后发现：准入 → 完成执行 → 配置变化 → 旧结果发布。

在修复获授权、无关条件满足且复验成功时，存在“登记修复 → 定向复验 → 通过 → 关闭”的路径。移除限定复验入口后无法到达关闭。这是有限模型中的条件可达性。

## 验证边界

尚未验证真实执行器、设备适配器、现场网络、完整并发及全部业务策略。路径采用显式有向集合，档位采用精确相等；测试调度、覆盖算法、窗口和豁免传播等待确认事项仍然保留。

仍需进一步审查的约束：ZTP完成、下发成功、配置生效是不同事实。；采集来源、发现来源、责任域是不同维度。；来源字段完整不足以证明物理事实正确，仍须独立样本和现场核验。
